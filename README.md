## ViaEMS FPGA Test Bench

This is verilog RTL and rust client tool for hardware intended to act as a test
harness/interface to a real ViaEMS target. The board provides a high-speed USB
interface to a Lattice MachXO3D FPGA, configured to talk an interface described
in INTERFACE with client software.  The commands loaded from the host describe a
sequence of outputs and emulated tlv2553 SPI responses, while collecting 24
inputs from the target at 60 MHz, effectively making this a combination 8-bit
waveform generator and 24 bit logic analyzer.  The client tool inputs a scenario
as generated by the viaems integration test framework and records the outputs to
a file.

The hardware design for the board current lives here: https://github.com/via/viaems-boards/tree/s32k342-board/test-harness

### Building
The rust commandline tool can built by running `cargo build -r` from the `src`
directory.

The gateware uses the yosys and nextpnr open source toolchain:
- yosys 0.54 or later
- nextpnr - g5194b5c or later (very recent support for pin io parameters)
- prjtrellis - built out of a branch until https://github.com/YosysHQ/prjtrellis/pull/257 is merged
recent nextpnr is required

Run `sh build.sh` in the `rtl` directory. This results in a design.bit, which
can be loaded into ram with:
```
openFPGALoader --ftdi-channel 1 design.bit
```
